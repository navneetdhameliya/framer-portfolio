## 1. What this is

Portfolio website for **Artonest Design Studio** (Framer designer & developer), built in
Next.js. The look is modelled on the "Helga" Framer template (helganielsen.framer.website):
warm off-white page, large serif headings, small uppercase labels. Only the layout, type,
colours and motion are borrowed. **None of that template's text, images or logo are used.**

- Live site: https://framer-portfolio-gules.vercel.app
- GitHub: https://github.com/navneetdhameliya/framer-portfolio (branch `main` only)
- Vercel: account `navneet-dhameliyas-projects`, project `framer-portfolio`
  (sign in with GitHub as `navneetdhameliya`). Every push to `main` deploys automatically.
- Owner email (inquiries go here): artonest.design@gmail.com

## 2. Rules for working on this project (from the user)

1. **Push straight to `main`. Never create branches.** Only push when the user asks
   ("push this update on main branch"). Workflow from `artonest/`:
   `git add -A`, commit, `git push origin main`. Check that no `.env*` file is staged.
2. After pushing, wait for the Vercel deploy and check the live site (GitHub's
   deployments API shows the status).
3. **Never ask for, accept or print secrets in chat** (Gmail App Password etc.). The user
   enters them in `.env.local` and Vercel themselves. Don't change Google/Vercel account
   security settings for them.
4. Test form emails without sending real mail (fake `fetch` in the browser, or send only
   requests that get rejected). Real test sends only if the user says yes.
5. Every change: run `npm run typecheck` and `npm run lint`, and look at it in the browser.

## 3. Gotchas

- **The folder path contains `&`**, which breaks Windows npm `.cmd` shims. So `package.json`
  scripts call `node node_modules/...` directly. Don't "fix" them back to `next dev`.
- **This is Next.js 16** (breaking changes vs. older versions). `AGENTS.md` says to read
  `node_modules/next/dist/docs/` before writing Next code. Page props use
  `PageProps<'/route'>` / `LayoutProps`, generated by `node node_modules/next/dist/bin/next typegen`
  (run it if types go missing after deleting `.next/types`).
- **Image cache:** `next/image` caches by file name. If you replace an image, give it a
  **new file name**, or old versions keep being served (this happened with thumbnails).
- **Fonts:** Boska and Switzer come from Fontshare, in **two separate `<link>` tags**
  (one combined request silently drops Switzer). See `src/app/layout.tsx`.
- **Local dev server:** `npm run dev` (port 3000). In Claude Code use `preview_start` with
  the config `artonest-dev` (`../.claude/launch.json`, one level above the repo, `autoPort`
  on). If port 3000 is taken by an old frozen server, stop that process first.
- Windows + Git Bash: be careful with backslashes in inline `node -e`/`python` snippets
  (a regex with `\r\n` got corrupted once). Write a small script file instead.

## 6. Design system (measured from the reference)

- Colours: page `#FFFEF5`, ink `#1C1E1E`, accent lime `#DAFF36` (now unused on the CTA
  panel, which is black), muted `#B6B6B6`.
- Fonts: **Boska** 700 (display serif), **Switzer** 400/500/600 (body, labels).
- Content width: `container-site` = max 1440px, 20px side padding, used by every section.
- Breakpoints: 810px (tablet) and 1200px (desktop).
- Easing everywhere: `cubic-bezier(0.12, 0.23, 0.13, 0.96)`.
- Motion: header slides down on load; headings drop in word by word (`SplitHeading`);
  blocks fade up on scroll (`Reveal`); labels roll on hover (`RollText`).

## 7. Current state (what exists and works)

- **Header:** "Home" on the left, logo in the centre, "Contact us" on the right (links to
  `/contact`). Phone menu has Home and Contact us. Gets a blurred background after scrolling.
- **Home:** hero titled "Artonest Framer Portfolio" with a "Contact us" button (to
  `/contact`); "Selected work" grid of **27 projects** (3 columns desktop, 2 tablet, 1 phone,
  4:3 cards). Each card opens the project's live site **in a new tab** (there are no
  project detail pages, by request). Card text: bold title, industry, site address.
  Black "Let's work together" panel with a light "Contact us" button.
- **Thumbnails:** 11 projects use designed 1600x1200 WebP thumbnails from `public/images/thumbnails/`
  (Tamayo, ECS, GLX, Victoria Ulwatu, Kennedy & Co., HD Visual Story, Excerra, Oseille TV,
  Zorgsense, Center Medical Decointe, Noca Media). Zorgsense also has a hover image.
  The other 16 (including **Zyvyo, deliberately kept as a website screenshot**) use
  screenshots from `public/images/work/`. Register thumbnails in the `thumbnails` set in
  `src/data/projects.ts`.
- **Contact page** (`/contact`): form with Name, Email, Project type (10 options),
  Budget range (4 options), Message, honeypot, and Submit. "Or email" link on the left,
  Submit on the right. Below it, a black "Hire me on" panel with Upwork / Framer / Contra cards.
- **Contact form behaviour:**
  - Email is trimmed and lowercased on submit (uppercase typing is fine).
  - Invalid format: pop-up "Please enter a valid email address." (+ "Did you mean…?" for typos).
  - Domain can't receive mail, or looks like a typo of gmail/yahoo/etc.: "This email doesn't exist".
  - Valid: pop-up "Thank you! / Your email has been sent successfully. Thank you for reaching out."
    and the inquiry is emailed in the background via `/api/contact`. Failures are only logged
    (Vercel -> Logs), never shown to the visitor.
  - The inquiry email arrives as a table: Name, Email, Project type, Budget, Message; Reply goes
    to the visitor.
  - Limit: no site can confirm a specific inbox exists; only format/domain are checked.
- **Footer:** Website (Home, Contact), Follow (Instagram, Behance, LinkedIn), Contact (email,
  phone 079841 79697), faded "Artonest" wordmark. **Bar under the footer:** "Hire me on Upwork"
  link plus Framer and Contra buttons. All outside links open in a new tab; the email address
  opens a Gmail compose window in a new tab.
- Removed on purpose: the About page, testimonials, project detail pages, the email menu
  (Gmail/Copy), FormSubmit.
